# 한강, 우리 둘

음악에 반응하는 한강 불꽃축제. Three.js 3D 야경·구형 불꽃·수면 셰이더 (미지원 기기는 2D), Web Audio 주파수 분석, 유튜브 영상/라이브/플레이리스트, 로컬 음악 파일, 전체 화면 감상.

## 실행
Node 22.13 이상에서 `npm install`, `npm run dev`.
검증: `npm run build`, `npx tsc --noEmit`, `npm run lint`, `npm test` (렌더링 검사는 먼저 build 필요).

## 사용
1. 유튜브 주소를 붙여넣고 불러오기 → 플레이어에서 재생.
2. 소리 연결 → 음악이 나오는 Chrome 탭 → 탭 오디오 공유.
3. 여기 앉아 감상하기. Esc로 설정 복귀, 하늘을 누르면 불꽃 추가. 드래그·방향키로 시점을 돌리고 R로 정면 복귀.

현재 탭이 공유 목록에 없으면 유튜브에서 열기로 별도 탭을 열어 연결한다. 운영체제별 전체 소리 공유 지원은 다르다. 음악 파일을 선택하면 별도의 소리 공유 없이 반응한다. 음악 입력이 연결된 상태에서 무음이면 새로운 불꽃을 쏘지 않는다. 파일 일시정지/종료와 연결 해제 후에는 자동 불꽃으로 돌아온다.

효과음은 직접 합성한 소리이며 중계 녹음을 배포하지 않는다. 공유 소리는 재출력하지 않아 에코를 방지한다. 유튜브 플레이어는 감상 모드에서도 보이고 조작 가능하다. 비공개/임베드 제한/광고/지역 제한은 유튜브 정책을 따른다. 오디오 공유의 권한 승인과 실제 출력 장치 동작은 사용자 환경에서 확인해야 한다.

## 참고 및 검증 범위
2026-09-05 한화 공식 생중계 https://www.youtube.com/watch?v=nLZKpuCxmpM 의 짧은 DVR 구간을 확인했다. 강변 5개 지점의 부채꼴 동시 발사, 금빛·분홍빛과 강 위 반사, 잔연을 참고했다. 오디오는 청취하지 못했고 18초 PCM 파형의 강약 및 onset 간격만 분석했다. 효과음은 실황 복제가 아닌 별도 합성이다.

성공 기준: 한강 야경/불꽃/반사, 음악의 강약에 반응하고 무음에서 발사 억제, 유튜브·로컬 음악 진입점, 전체 화면/일시정지/재개, 정적·빌드·렌더링 검증 통과.
3D는 앉은 높이의 카메라, 돗자리·잔디·다리·도시·발사대, 구형 입자와 잔광, 수면의 흔들리는 반사, 입체 잔연을 렌더링한다. 소리는 거리/343초 지연과 좌우 패닝을 적용한다.

테스트는 URL 10가지, 2D 폴백의 가상 Canvas에서 무음/음악/일시정지/자동 재생/정리 5가지, 서버 HTML을 검사한다. 실제 브라우저 화면·오디오 권한 팝업·유튜브 외부 재생은 자동 검증하지 않았다.

## Railway 배포
GitHub 저장소를 Railway 서비스에 연결하면 Dockerfile로 빌드하고 `npm start`로 실행한다. `PORT`는 Railway가 제공하는 값을 사용하며 `0.0.0.0`에 바인딩한다. 공개 도메인의 `/`가 HTTP 200을 반환해야 배포가 정상으로 판정된다. 기존 Sites 배포 설정도 유지한다.
